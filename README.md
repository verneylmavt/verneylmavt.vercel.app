# verneylmavt.vercel.app

Repository of verneylmavt.vercel.app.

This repository contains the full evolution of my personal website across multiple iterations, reflecting how both the design and engineering approach have matured over time. Each version explores different architectural decisions—from a lightweight static implementation to a modern, component-driven application with advanced animations and WebGL-based visuals.

Rather than maintaining a single continuously modified codebase, the project is structured into versioned branches to clearly capture these transitions. This allows each iteration to stand on its own as a snapshot of how the system was designed, built, and improved, making the repository not just a portfolio website, but also a record of my frontend and product engineering progression.

## Branches

- **`main`**
- [**`v1`**](https://github.com/verneylmavt/verneylmavt.vercel.app/tree/v1): HTML + CSS + JavaScript
- [**`v2`**](https://github.com/verneylmavt/verneylmavt.vercel.app/tree/v2): Next.js + Tailwind CSS + Framer Motion + React Three Fiber + Three.js + WebGL
